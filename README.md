## The entry

> "In my defense, the map showed a road, the road was a lake, and I refuse to apologize to a lake that was clearly parked in the wrong place."

## How it works

`main.ts` writes the GPS's one-line excuse (138 characters, a single line, punchline at the end) to `/output/entry.txt`. Run it locally with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
